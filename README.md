# Семейный бюджет-бот

> Telegram-бот для совместного учёта доходов и расходов с автоматической категоризацией через GPT-4o.

---

## Описание проекта

Бот позволяет двум пользователям (муж и жена) вносить траты и доходы через Telegram в свободной форме — текстом или фото чека. GPT-4o автоматически распознаёт сумму и категорию. Все данные сохраняются в Google Sheets. В конце месяца владелец получает аналитический отчёт.

## Как работает бот

### Запись расходов
- **Текстом:** напиши что-то вроде `потратил 500 на кофе` → GPT парсит сумму и категорию → бот запрашивает подтверждение → запись в таблицу
- **Фото чека:** отправь фото → GPT Vision распознаёт позиции и сумму → подтверждение → запись

### Запись доходов
- Напиши: `пришла зарплата 50000` → GPT определяет тип операции → запись дохода

### Команды

| Команда | Доступ | Описание |
|---------|--------|----------|
| `/balance` | все пользователи | Баланс за текущий месяц |
| `/report` | только владелец | Подробный аналитический отчёт |

## Переменные окружения

Все переменные задаются в настройках проекта на Railway (Variables).

| Переменная | Описание |
|------------|----------|
| `TELEGRAM_TOKEN` | Токен бота от @BotFather |
| `OPENAI_API_KEY` | API-ключ OpenAI для GPT-4o |
| `GOOGLE_SHEETS_ID` | ID таблицы Google Sheets (из URL) |
| `GOOGLE_CREDENTIALS_JSON` | Содержимое JSON-файла сервисного аккаунта Google (в одну строку) |
| `MY_TELEGRAM_ID` | Telegram ID владельца — для доступа к команде `/report` |

## Восстановление при сбое

1. Открыть [Railway.app](https://railway.app) → войти в проект `patient-dedication`
2. Перейти во вкладку **Deployments** → посмотреть логи последнего деплоя
3. Если бот не отвечает — нажать **Redeploy** на последнем успешном деплое
4. Если ошибка в переменных — проверить вкладку **Variables**, убедиться что все пять переменных заданы
5. Если проблема с Google Sheets — убедиться, что сервисный аккаунт имеет доступ к таблице (Editor)
